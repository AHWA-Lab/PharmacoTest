# 에니어그램 문항 검토 및 개정

## 형식 확인

Enneagram Institute의 RHETI 안내는 144개의 진술 쌍에서 평소 자신에게 더 가까운 한쪽을 선택하도록 안내한다. 두 진술 모두 해당할 수 있다고 명시하므로, 에니어그램이 반드시 3지선다이거나 논리적으로 반대인 진술만 비교해야 하는 것은 아니다.

출처: https://www.enneagraminstitute.com/rheti-instructions/

이 프로젝트는 RHETI의 문항이나 채점법을 복제하지 않은 별도의 재미용 게임이다. 이번 개정 역시 심리측정 타당도나 진단 정확도를 검증한 검사라는 뜻은 아니다.

## 기존 문제

- ‘일이 제대로 되도록 기준을 확인’과 ‘누군가 나를 믿고 찾아오면 기쁨’처럼 상황·판단 기준이 다른 긍정적 진술을 붙여 두었다. 둘 다 해당할 때 무엇을 우선해야 하는지 모호했다.
- 일부 선택지가 다른 문항에 그대로 반복됐다.
- 기존 18문항을 늘린 뒤 단순 추출하면 유형마다 비교 기회가 달라져 단순 득표 수가 출제 빈도에 영향을 받는다.

## 변경

- 원문을 새로 작성한 상황형 50문항. 각 문항에 공통 상황을 먼저 제시하고, 같은 상황에서 어느 동기나 대응을 먼저 택하는지 비교한다. 선택지의 줄 위치는 기존처럼 무작위다.
- 예: ‘마감 직전, 결과물에 작은 결함을 발견했을 때’ → ‘평가가 늦어져도 기준에 맞게 고친다’ / ‘작은 결함은 남겨도 약속한 성과를 제때 낸다’.
- 9유형 사이의 모든 36가지 쌍을 포함하고 14개의 별도 상황을 더했다. 각 실행에서는 같은 유형 쌍을 중복 출제하지 않는다.
- 매번 15문항을 새로 선택하고 순서를 섞는다. 무작위로 고른 3유형은 각각 4번, 나머지 6유형은 각각 3번 비교한다. 총 30개의 선택지 노출이다.
- 점수는 유형별로 응답한 비교 횟수 대비 선택 비율을 우선한다. 동률이면 선택 수, 마지막 선택 순서로 결정한다. 무응답은 비교 횟수와 득표에서 모두 제외한다. 전부 무응답이면 기존 무작위 배정 안내를 유지한다.
- 10초 제한과 이전 문항 기능을 유지하며, 이전으로 돌아가도 해당 실행의 문항 구성이 바뀌지 않는다.

## 확인

500회 무작위 구성에서 15문항 중복 방지, 모든 유형의 3~4회 노출, 전체 50문항의 출제 가능성을 검사했다. 각 구성에서 9유형 모두 선택에 따라 결과로 나올 수 있는지 확인했다. 페이지 검사에서는 15문항 완료와 결과·궁합·도감·통계 이동을 확인했다.
